
# Customer Churn Prediction

## Overview
A machine learning project that predicts whether a
telecom customer is likely to leave a service.

## Dataset
IBM Telco Customer Churn dataset.

Dataset source:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Download the dataset and place the CSV file in the
data/ directory. The dataset is excluded from Git.

## Objectives
- Perform exploratory data analysis (EDA).
- Clean and preprocess customer data.
- Train and compare classification models.
- Evaluate models using appropriate metrics.
- Build a simple customer churn prediction interface.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
